# Маппинг. Система распределения заказов сервиса доставки еды

**Карякин Платон Евгеньевич, гр. 5130904/40102. Вариант 9**

Оригинальный документ: [mapping.docx](source/mapping.docx).

| Элемент СМО | Сущность бизнес-домена | Назначение |
| --- | --- | --- |
| **Источник** | Канал оформления заказа: Премиум-подписка (№1), Мобильное приложение (№2), Веб-сайт (№3) | Оформление заказа клиентом через канал создаёт заявку на распределение. Источник — ИБ (бесконечный); поток заявок от одного канала пуассоновский, интервалы между заявками распределены экспоненциально (ИЗ1). Номер источника определяет приоритет заявки при формировании пакета (Д2Б5). |
| **Заявка** | Заказ на доставку | Один запрос на доставку еды. Содержит состав заказа, адрес доставки, номер канала-источника (приоритет), порядковый номер заявки и время поступления в систему. |
| **Буферная память** | Общая ограниченная очередь диспетчерской системы распределения заказов | Хранит заявки, ожидающие назначения курьера. Новая заявка встаёт в конец очереди; при изъятии заявки остальные сдвигаются к началу, пропусков в очереди нет (Д1ОЗ2). |
| **Прибор** | Курьер | Доставляет один заказ за раз. Длительность доставки (время обслуживания) имеет равномерное распределение (ПЗ2). Приоритет курьера при поиске определяется его номером (Д2П1). |
| **Диспетчер постановки** | Компонент приёма заказов | Помещает новую заявку в конец буфера по Д1ОЗ2; не имеет сведений о занятости курьеров. При переполнении применяет Д1ОО5: отказ получает вновь пришедшая заявка, состояние буфера не меняется. |
| **Диспетчер выбора** | Планировщик назначения курьеров | При освобождении курьера или появлении заявки в буфере формирует пакет заявок самого приоритетного источника (Д2Б5) и выбирает из него заявку; находит свободного курьера поиском от №1 (Д2П1) и назначает её. Пакет не расширяется заявками, пришедшими позже; все курьеры обслуживают только его, пока не завершены все заявки пакета (включая обрабатываемые), затем формируется новый. |
| **Отказ** | Отменённый заказ («нет свободных курьеров») | При заполненном буфере отказ получает именно вновь пришедшая заявка — без назначения курьера и без вытеснения уже стоящих в очереди. Отказ учитывается источнику, сгенерировавшему заявку; буфер не изменяется (Д1ОО5). |
| **Обслуживание** | Доставка заказа | Курьер доставляет заказ клиенту. После доставки курьер освобождается и становится доступен для следующего назначения. |
| **Выход из системы** | Доставленный или отменённый заказ | Заявка покидает систему после доставки либо сразу при отказе. Исход учитывается в статистике: сводная таблица в автоматическом режиме (ОР1); текущее состояние модели и табличный календарь событий в пошаговом режиме (ОД3), без построения временной диаграммы. |
