# Диаграммы

| Файл | Назначение |
| --- | --- |
| sequence-main | Полный цикл: HappyFlow, отказ, занятость курьеров и сквозной сценарий с альтернативами |
| sequence-happy | Буфер и курьер свободны, ожидание равно нулю |
| sequence-overflow | Д1ОО5 — отказ новой заявке при переполненном буфере |
| sequence-batch | Подробный алгоритм выбора заявки и курьера: Д2Б5 и Д2П1 |
| classes | Классы, поля, методы, приватные ссылки между компонентами |
| flowchart | Общая блок-схема цикла обработки событий с дорожками |
| flowchart-dispatch | Подробная блок-схема выбора заявки и курьера со всеми альтернативами |

Для каждой диаграммы есть `.puml`, `.svg` и `.png` с одним именем.
`.puml` — редактируемый исходник, `.svg` удобно увеличивать, `.png` удобно
вставлять в отчёт. После правки исходника повторно отрендерить можно через
`tools/render_diagrams.py` (нужна сеть) или `plantuml.jar` (офлайн, нужна
Java) — см. [tools/README.md](../../tools/README.md).
